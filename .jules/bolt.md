## 2025-02-17 - [Route-based Code Splitting in Vite + React App]
**Learning:** Statically importing heavy React components that load complex visualization libraries (like `recharts` and `lucide-react`) into the main route definition results in a bloated initial bundle size (over 660 kB). By leveraging `React.lazy()` and `React.Suspense` for route-based code-splitting, Vite is able to split the vendor libraries and page bundles into smaller, on-demand loaded chunks. This reduces the initial JS bundle size from 660 kB to 265 kB (a ~60% reduction in initial load payload), improving Time to Interactive (TTI) and First Contentful Paint (FCP) significantly.
**Action:** Always identify route components or heavy below-the-fold dynamic widgets that use large third-party libraries and implement code splitting using React.lazy / dynamic import.
