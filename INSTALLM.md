# OpenClaw Installation Guide

## Requirements

- Debian 12
- Docker
- Git
- Internet connection

## Installation

1. Update the system.
2. Install Docker and Git.
3. Clone the repository.
4. Configure the environment.
5. Start OpenClaw.

## Verification

After installation, verify that all services are running correctly.
